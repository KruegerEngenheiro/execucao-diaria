# Execução Diária

Meu sistema pessoal de execução. Rotina, tarefas, tempo, resultados e evolução, num PWA que instala na tela inicial do iPhone e funciona offline.

Não é uma lista de tarefas. Transforma tempo em execução, execução em resultado e resultado em evolução.

## Rodar no computador

```
npm install
npm run dev
```

Abre em `http://localhost:5173`.

Outros comandos:
- `npm test` roda os testes.
- `npm run build` gera a versão de produção na pasta `dist`.
- `npm run preview` serve a versão de produção pra conferir.

## Instalar no iPhone

1. Abra a URL no Safari do iPhone.
2. Toque no botão de compartilhar.
3. Toque em "Adicionar à Tela de Início".

Os dados ficam salvos no próprio aparelho e funcionam sem internet.

## Como foi construído

A pasta `docs/` tem requisitos, arquitetura, UX, design system, modelo de dados, regras de negócio, testes e roadmap.
